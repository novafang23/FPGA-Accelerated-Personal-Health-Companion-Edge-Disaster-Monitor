## 1. Quick Start: How to Import into EasyEDA Pro

You can bring this design into **EasyEDA Pro (v2.x / v3.x)** using any of the following three workflows:

### Method A (Recommended): Netlist Import (Direct to PCB)
1. Open **EasyEDA Pro**.
2. Click **File** $\to$ **Import** $\to$ **KiCad**.
3. Select the file:  
   [`SCHEMATICS/valor_system_schematic.kicad_sch`](file:///C:/Users/abhin/OneDrive/Desktop/verilog/SCHEMATICS/valor_system_schematic.kicad_sch)
4. EasyEDA Pro will parse the schematic sheets, symbols, power ports, and net labels automatically.

### Method B: Component Placement via BOM
1. Create a new Project in EasyEDA Pro.
2. Select **File** $\to$ **Import** $\to$ **Netlist**.
3. Choose format **Protel / Altium / Telesis** and select:  
   [`SCHEMATICS/valor_netlist.net`](file:///C:/Users/abhin/OneDrive/Desktop/verilog/SCHEMATICS/valor_netlist.net)
4. EasyEDA Pro will immediately generate all ratsnest connections and pin assignments on your PCB.

## 2. Pinout Corrections (Fixing Draft `SCH_Schematic1_1-P1`)

The previous draft schematic ([`SCH_Schematic1_1-P1_2026-10-02.png`](file:///C:/Users/abhin/OneDrive/Desktop/verilog/SCHEMATICS/SCH_Schematic1_1-P1_2026-10-02.png)) contained several pin collisions. The table below provides the authoritative hardware mapping:

### A. Chip-to-Chip FPGA SPI Link (Mode 0, 1 MHz Runtime)

| Signal | ESP32-S3 Pin | FPGA SLG47910V Pad | Net Name | Purpose / Hardware Invariant |
|---|:---:|:---:|---|---|
| **SPI Clock** | **GPIO 12** | **PIN_16** | `SPI_SCK` | SPI Mode 0 clock generated by ESP32 `spi_master` |
| **Chip Select** | **GPIO 10** | **PIN_17** | `SPI_SS_N` | Active-low manual CS driven per 8-bit transaction |
| **Data In** | **GPIO 11** | **PIN_18** | `SPI_MOSI` | Raw optical IR sample (`sample[7:0]`) sent to FPGA |
| **Data Out** | **GPIO 13** | **PIN_19** | `SPI_MISO` | FPGA reply: `{beat_latched, filt_sample[6:0]}` |
| **FPGA Enable** | **GPIO 8** | **PIN_11** | `PIN_FPGA_EN` | Boot-mode latch & enable |
| **FPGA Power** | **GPIO 9** | External FET | `PIN_FPGA_PWR` | Power-gating control for ForgeFPGA rail |
| **Heartbeat LED** | — | **PIN_7** | `LED_USER_PULSE` | Pulses Blue LED D12 on hardware systolic detection |

> [!WARNING]
> **Old Draft Collision Note:** The draft had `SPI_SS` on IO9, `SPI_MOSI` on IO10, `SPI_SCK` on IO11, and `SPI_MISO` on IO12. This mismatched the ShrikeFi PCB layout. The corrected table above reflects the true physical PCB traces.

### B. Shared I2C Sensor Bus (400 kHz Fast-Mode)

All I2C peripherals share **GPIO 1 (SDA)** and **GPIO 2 (SCL)** with $4.7\text{ k}\Omega$ pull-up resistors to 3.3V:

| Device | Device Name | 7-Bit Address | Connections | Power Rail |
|---|---|---|---|---|
| **U3** | MAX30102 Optical Biosensor | `0x57` | SDA $\to$ GPIO 1, SCL $\to$ GPIO 2, INT $\to$ NC | 3.3V (VLED, VDD) |
| **U4** | BME280 Environmental Sensor | `0x76` | SDA $\to$ GPIO 1, SCL $\to$ GPIO 2, CSB $\to$ 3.3V, SDO $\to$ GND | 3.3V |
| **DISP1** | SSD1306 0.96" OLED Display | `0x3C` | SDA $\to$ GPIO 1, SCL $\to$ GPIO 2 | 3.3V |
| **Pull-Ups** | $R_1, R_2$ ($4.7\text{ k}\Omega$ 0603) | — | $R_1$ across 3.3V $\leftrightarrow$ SDA; $R_2$ across 3.3V $\leftrightarrow$ SCL | 3.3V |

### C. Plantower PMS5003 Air Quality Sensor (UART1)

| Connector Pin | Function | Connects To | Voltage Constraint |
|:---:|---|---|---|
| **Pin 1** | VCC | **+5V (USB VBUS)** | 5.0V strictly required for internal fan & laser |
| **Pin 2** | GND | **GND** | Common ground |
| **Pin 3** | SET | **+3V3** or Open | Normal operation |
| **Pin 4** | RX (Module RX) | **ESP32 GPIO 18 (TX)** | 3.3V UART |
| **Pin 5** | TX (Module TX) | **ESP32 GPIO 14 (RX)** | 3.3V UART (ESP32 internal pull-up enabled) |
| **Pins 6–8** | RESET, NC, NC | Unconnected | Leave floating |

## 3. Power Architecture & Decoupling Capacitor Network

```text
               ┌─────────────────┐
 5V USB-C ────▶│ U5: AP2112K-3.3 │────▶ +3V3 Rail (ESP32-S3, Sensors, FPGA VDDIO)
 (J2 / 5V_EXT) │ (600mA Low Drop)│      ├── C1 (10uF) + C2 (0.1uF)  [ESP32]
               └─────────────────┘      ├── C3 (0.1uF)              [FPGA VDDIO]
                                        ├── C6 (0.1uF) + C7 (10uF)  [MAX30102]
                                        ├── C8 (0.1uF)              [BME280]
                                        └── C9 (10uF)               [OLED]

 ForgeFPGA SLG47910 Core:
 +3V3 ──▶ Internal 1.2V Core Regulator (Pin 22 VDDC)
          └── C4 (0.1uF) + C5 (4.7uF) to GND (Mandatory stability network)
```
